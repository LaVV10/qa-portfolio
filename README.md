# QA Portfolio

Портфолио выполненных QA-проектов: ручное тестирование Web UI и REST API, анализ результатов и базовая автоматизация.

## Проекты

| Проект | Формат работы | Результат |
| --- | --- | --- |
| [ToonyGamy](projects/toonygamy/README.md) | Manual QA, API testing, UI/API automation | 22 API-запроса, 20+ баг-репортов, автотесты на Playwright |
| [Paddit](projects/paddit/README.md) | Ручное UI-тестирование и регрессия | 6 тестовых сессий, 28 баг-репортов, 14 подтверждённых исправлений |
| [VPN-сервис](projects/vpn/README.md) | Ручное функциональное тестирование | Проверка пользовательских сценариев и обработки ошибок |

## Что демонстрирует портфолио

- проектирование тестовых сценариев и чек-листов;
- функциональное, smoke-, регрессионное и исследовательское тестирование;
- проверка REST API: HTTP-методы, статусы, валидации, права доступа и JSON;
- оформление баг-репортов и повторное тестирование исправлений;
- работа с Chrome DevTools, Postman, Java, JUnit 5, Playwright, TypeScript, SQL и Git.

## Безопасность публикации

В репозитории нет тестовых учётных данных, токенов, внутренних URL, приватных данных, исходного кода сторонних продуктов и шагов воспроизведения незакрытых критичных дефектов. Описания содержат только безопасные для публичного портфолио результаты работы.
